# anon_bot_tg

Телеграм-бот на Go для анонимных сообщений по личным ссылкам.

## Как работает
- По команде /start бот выдаёт пользователю его уникальную ссылку вида https://t.me/имя_бота?start=ID.
- Когда другой человек переходит по этой ссылке, бот связывает их в базе данных, и всё, что отправляет гость (текст, фото, видео или стикеры), пересылается владельцу ссылки анонимно.
- Чтобы ответить отправителю, владельцу достаточно сделать свайп (Reply) на входящее сообщение — бот найдёт ID отправителя в базе по ID сообщения и перешлёт ответ обратно.

## Стек
- Go (telego)
- PostgreSQL (pgx/v5, хостинг Neon)
- Деплой на Render

## Структура проекта
- base.go — точка входа, запуск HTTP-сервера для health-check, Long Polling и обработка /start.
- text.go, picture.go, video.go, sticker.go — хендлеры для пересылки разных типов сообщений и ответов на них.
- database/ — подключение к PostgreSQL и SQL-запросы для сохранения и поиска связок пользователей.

## Запуск
Для работы нужно задать две переменные окружения:
- TOKEN — токен телеграм бота из BotFather
- DATABASE_URL — строка подключения к PostgreSQL
